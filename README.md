# 🚢 Titanic Data Analysis

This project is a data analysis notebook exploring the famous Titanic dataset using Python, pandas, and matplotlib. The goal is to uncover demographic patterns and survival insights through visualizations and basic statistics.

---

## 📂 Dataset Used

- **File**: `tested.csv`  
- **Source**: [Titanic Dataset - Kaggle](https://www.kaggle.com/c/titanic/data)  
- **Columns** include: `Sex`, `Age`, `Pclass`, `Fare`, `Survived`, `SibSp`, `Parch`, and more.

---

## 📊 Analysis Performed

1. **Average Age**  
   - The average age of passengers was **30.27 years**.

2. **Gender Distribution**  
   - Around **64% of passengers were male**.
   - Gender ratio visualized with a pie chart.

3. **Survival Based on Gender**  
   - **No men survived** in this subset of data.
   - All survivors were **female**.

4. **Class-wise Survival Rate**  
   - Nearly **50% of survivors were from First Class**.
   - This indicates class had a strong impact on survival.

5. **Age Group Analysis**  
   - Most passengers were **adults (age 19–60)**.
   - Age distribution was visualized using bar charts.

---

## 🧠 Key Takeaways

- Survival was highly correlated with gender and class.
- Adults made up the majority of travelers.
- Visual analysis helps reveal hidden patterns in historical datasets.
